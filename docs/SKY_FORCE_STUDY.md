# Sky Force 真机观察与实现设计

采集：2026-10-27，用户的 iPhone 17。已实际打开 `pl.idreams.skyforcehd`（Sky Force）与 `pl.idreams.SkyForceReloaded2015`（Sky Force R.）；未读取版本号。15 张原始截图与时间戳见 [采集目录](reference/sky-force-2026-10-27/manifest.json)。这些是内部研究证据，不进入 App 的 Resources，也不作为发行素材。

## 观察范围与设备交接

按 `/tmp/iphone17-agent-queue.md` 排队，Sky Force → SenPlayer → AuvRouter。控制中心确认媒体音量 0%，保持勿扰模式；没有外放、录音或声纹分析。完成后两款游戏都已 terminate，分别查询到 state=1（not running），释放队列。试玩会改变游戏的正常局内进度：第一版进入第一关后撤退，获得少量星星；Reloaded 进入既有第四关，截图中飞机次数由 10/10 到 9/10。没有购买、升级消费、广告观看或存档重置。

本轮观察了菜单、出击、机库、道具说明、云层下降、地表、敌机、弹丸、星星、救援、受击和暂停。没有通关两款游戏、没有观察它们所有 Boss/全部关卡、没有采集结算动画；不能据此宣称全量或像素一致复刻。

## 本轮代码落点与验收

1. `SpriteArt.swift`：共用地表着色、边缘空气层、敌弹亮芯、分层爆炸、补给文字。五关通过 biome 选择表现，横向关卡继续复用世界坐标旋转。
2. `CampaignView.swift`：出击前显示真实存档中三项勋章状态与首次奖励。已获得奖励不再标为可重复领取。
3. `AudioScore.swift` / `BattleScene.swift`：救援、一般补给与普通星晶分开提示；音频仍本地合成，关闭声音时不播放。
4. UI 回归：地图/机库/出击、五 Boss 的两轴投影、横向补给、暂停与胜利；核心检查既有奖励去重、旧存档和音频 PCM。

控制成本：地表只加每像素运算，不每帧生成纹理；雾层复用有限节点；爆炸与文字进入既有到期回收路径；不增加依赖。新材质/雾不改变碰撞、伤害、掉落概率或存档字段。

实现与验证已落地，见 [实际截图](screenshots/v13/README.md) 与 [验证记录](VALIDATION.md)。50 项核心测试、4 项定向 UI 回归及最终五 Boss 渲染复测通过；unsigned iOS Release 构建成功。当前仍是原创风格化程序地形，不能等同于原版美术精度或全面 1:1 复刻。

## 后续关卡与上架

第一章继续五关。后续新关需要任务数据、敌方身份、背景/入场/阶段/结局台词、Boss 差异、掉落与目标，再用相同两轴渲染路径验收。当前剧情及地图节点仍按顺序任务 ID 对齐；增加关卡时需同步章节、路线位置和存档允许的关卡范围，不宣称只加 JSON 就能发布。

视觉验收分三步：模拟器确认布局与渲染；真机确认读弹、触控、连续长局温度/帧率；TestFlight 确认签名、音频中断与存档升级。App Store 前需替换或清点所有发行资产权利、完成实际设备截图与隐私说明。商店标题、角色、模型、图标和音频均使用本作原创内容；研究截图不作为商店宣传图。

尚待：两版 Boss/结算的补充采集、可静默获取并实际试听的音轨研究、真机性能测量与正式配音。本轮不把这些列为已完成。

对照使用完整截图，按宽度统一尺度，不裁掉差异。两款游戏的进度、升级数量、币种与文案不同，因此工具分数只作为画面接近程度的辅助证据，不代表功能或像素一致认证。最终截图及完整对照记录见 [v14](screenshots/v14/README.md)。目前仍有原创海岸轮廓、飞机线稿细节、字体，以及战斗地表/模型精度差异。


## 第十六版：比例与投放反馈

用户指出掉落包、飞行员与整体风格不搭，以及敌人和掉落过度聚集。本轮用独立的军工风格素材替换临时几何外观：短翼黄机、四发重装机、后掠红色截击机、履带坦克、双管炮、旧金属箱与正常比例飞行员。对照重点是材质、轮廓、尺寸和层次，不声称原作全部敌种已经复刻。

本轮没有再次占用手机。参考仍为本文件开头的实际截图；没有新增原版 Boss、音效或后期关卡观察。海面采用深蓝波纹、海岸带碎浪与浅滩，减少大面积白色泛光；锁定曝光，防止暗场景被自动提亮。水域地面单位和救援点加入礁台。

用户新要求明确涉及玩法，因此本次同步取消提前补兵与高频叠加掉落：按时间表展开编队，前 28 秒无装备箱，至少 22 秒/8 杀冷却，同屏一箱；按关卡扩展装备池。详见 [当前设计规则](GAME_DESIGN.md)。这不是对原作隐藏概率或内部算法的推断。

未完成的视觉匹配项：五 Boss 仍共用母体，沙漠/冰川/轨道的场景块与细节变化仍不足，缺少原作全敌种对应研究；这些不能用自动测试通过来宣称已达到一致。后续扩展以原版实际观察与同状态画面对照为依据。
