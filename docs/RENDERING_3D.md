# 全场景 3D 渲染

## 坐标与职责

GameWorld 保持原来的二维街机战斗模拟。x 为横移轴，y 为前进轴，z 为真实几何深度。战机与弹丸中心放在 z=65；地面低于飞机，模型绕 y 轴侧倾、x 轴俯仰，护盾单独跟随。正交相机沿 -z 看向世界，因此高度与透视不会改变碰撞点的屏幕位置。横向飞行的相机绕 z 旋转 +90°，输入坐标仍使用原有 -90° 场景变换。

BattleCanvas 中只有 SCNView 绘制世界。透明 SKView 仅提供现有 update 时钟、触摸映射与暂停行为，没有任何精灵或绘制节点。SwiftUI 负责操作按钮、HUD、故事头像与字幕。渲染资产不进入存档，GameWorld 不依赖 SceneKit。

## 飞行姿态与输入

BattleScene 的相对拖动累计到 GameWorld 的受限目标位置，每帧 updateSteering 平滑移动真实碰撞中心。指数响应为 0.14 秒，限制最大追随距离、速度与松手后的残余位移，避免快速滑动造成长距离追赶。暂停和手势取消立即清空目标。

CombatRenderer 从真实位移/帧时长计算速度，用 0.085 秒响应平滑 FlightAttitude。侧倾上限 0.78 弧度，正横移使右翼下沉，偏航为侧倾的反向 12%；前后移动驱动俯仰。所有姿态绕碰撞中心旋转，镜头与投影不变。战机新增有厚度的双尾翼；低效果模式只使用四分之一姿态幅度。道具本体和收集闪光都不再绘制圆环。

## 生命周期和性能

实体按模拟 id 增删，材质按颜色/发光/金属参数缓存。相同地形瓦片共享几何，水平峡道网格按 20 Hz 刷新，波形与真实碰撞复用 corridor。效果到期移除；低效果模式减少碎片和烟雾。SCNView 使用 2× 抗锯齿与 60 FPS 目标；机库为 30 FPS。目标帧率不是测得帧率，真机长局性能尚需测试。

暂停设置两个场景 isPaused；离开页面释放 SCNView.scene，停止语音和战斗音效。装饰性 3D 场景从辅助功能子树隐藏，由稳定的 SwiftUI HUD 提供语义，避免测试或 VoiceOver 扫描逐帧销毁的图形节点。

## 验证

Debug 自检覆盖主机、普通敌机、五个 Boss、三种地面单位和九种补给：必须有深度、材质，不能使用 SCNPlane 或 UIImage 冒充模型。地形网格校验索引、有限顶点和非零法线。新增 UI 测试通过真实 SCNView 投影和输入视图坐标比较，检查两种飞行轴在不同高度下的对齐，并保存五个 Boss 的实渲截图。

既有回归继续检查五关、武器和护航、暂停、坠毁、Boss 击落、胜利与奖励、人物通讯与序幕。最新运行证据见 VALIDATION.md。

## 边界

这是保留街机射击规则的实时 3D 渲染升级，不改变关卡和伤害平衡。场景为原创风格化程序模型；人物肖像和 HUD 仍是二维信息界面。物理 iPhone 的功耗、热降频、内存峰值、无障碍实机体验，以及 App Store 签名上架验收未完成。
