# Sky Force：形态与场景结构对照

观察日期：2026-10-27。目标是轮廓、构造、运动与战场空间；颜色变化不计为新增形态。

## 证据与统计口径

- [Sky Force Reloaded 官方 iOS 页面](https://apps.apple.com/us/app/sky-force-reloaded/id976116090)：在本机 Edge 查看五张战斗截图；播放 30 秒预览并抽看战斗片段（约 17.5 秒有大型目标和分散弹道），没有完成逐帧视频分析。截图留存在 `reference/enemy-shapes-2026-10-27/app-store-gallery-last.png`。
- [社区敌人图鉴](https://sky-force-reloaded-2016.fandom.com/wiki/Enemies)：读取表格，排除表头和节日条目后有 **51 条**。其中含容器、障碍、辅助单位和武器变体，**不是 51 种独立敌人轮廓，也不是官方总数**。原始名称、关卡及图片来源在同目录 `catalogue.json`。
- 从图鉴直接打开并观察 Gunship、Heavy Gunship 1、Interceptor、Spider Railgun、Stage 12 Drone 的图片。社区称为 P-38 / Me 262 的名称仅是其分类标签；不当作官方命名。
- 本轮没有新增真机观察：先前使用的 iPhone 17 当前未连接。没有操作其他任务的手机。
- `reference-board.html` 只是带外部图片链接的研究索引；本轮未完成渲染检查。参考图片不进入游戏资源目录，新增模型由项目代码构建。

## 形态分类：避免把换武器、换色重复计数

| 结构家族 | 图鉴中的代表 | 要抓住的结构 |
|---|---|---|
| 螺旋桨编队机 | Prop Plane | 直翼、细机身、尾翼、螺旋桨；图鉴描述为无武装碰撞威胁 |
| 双尾梁 / 喷气固定翼 | P-38、Me 262、Missile Plane | 中央短舱、分开的发动机与尾梁，或翼下发动机 / 导弹挂架 |
| 旋翼机 | Helicopter、Heavy Helicopter、Elite、Experimental | 主旋翼、长尾梁、尾桨、机身短翼、炮舱；重型不能只放大贴图 |
| 辅助飞行器 | Maintenance Helicopter、Hot Air Balloon | 维修/运输用途与战斗机分开统计 |
| 无人机 | Drone、Volatile、Laser、Drone Fighter、Heavy Defense、Sawblade | 球形/盘形核心、外置推进舱、锯刃或武器模块；各变体需再逐图确认 |
| 履带与轮式底盘 | Battle Tank、SAM/Gatling/Railgun Tank、APC、Buggy、Mobile AA | 底盘和炮塔分开；履带、轮组、炮管、火箭巢改变剪影 |
| 固定炮座 | AA、Laser、Energy、Radial、Flamethrower、Mantis、Plasma、SAM 等 | 基座、旋转座和炮管层级；同底座换弹种不自动算新轮廓 |
| 足式机械 | Spider Railgun、Laser Spider、Energized Spider、Spiderbot | 外展关节和足端、中央壳体、长导轨；已查看的 Spider Railgun 有六条支腿 |
| 舰艇 | Missile Patrol Boat | 尖艏、长船体、舰桥、甲板发射器，不能用飞行机身替代 |
| 危险物与目标物 | AA Mine、Laser Fence、Nuclear Missile、Container | 独立统计，不混入普通飞机种类 |

图鉴还有重型炮弹炮塔、激光鞭炮塔等条目，详见完整索引。上述分组不是穷尽所有独立剪影的最终计数。

## 官方截图确认的场景语言

1. 沙地峡谷：横跨战场的桁架桥，岩壁高差、道路和方形抬高炮位。桥墩、斜撑产生可辨认的空间层级。
2. 工业内场：纵向管道、格栅、接缝、井道，以及多臂分节机械 Boss。大块面与细部有明确比例。
3. 绿色军事区：钢结构跨越战场、地面裂缝、旋翼机和弯曲导弹烟迹。
4. 夜间设施区：大直径断管、建筑、箱体、碎石，不是仅把白天地表染蓝。
5. 狭长岩岸：炮台、履带单位、旋翼机分布在岸线与通道两侧，近远层次不同。

当前项目之前主要是重复的边缘岛屿/礁石，缺少横跨构造和中段设施；三个固定翼轮廓不能覆盖原版的结构家族。五个 Boss 共享母机壳也会削弱关卡识别。

## 本次实现与来源边界

### 普通空中单位：8 类

- 保留：侦察喷气机、四发装甲机、截击机。
- 新增：直翼螺旋桨机、武装直升机、双尾梁机、重型直升机、三推进舱无人机。
- 模型使用立体部件及参考项目现有战机制成的新共享装甲面板材质（内置 image_gen，提示词和资源路径见 `reference/enemy-shapes-2026-10-27/asset-prompt.md`）。直升机包含独立旋翼和尾桨；双尾梁机有两条尾梁和连接尾翼；无人机取消驾驶舱/机翼，使用中央壳体及外置推进舱。
- 行为：螺旋桨机不射击；直升机入场后短暂停留，随后离场；双尾梁机发射平行三路弹；无人机先对准玩家再沿已确定方向突入。这些是适配本项目的规则，不声称逐项等同原作。

### 地面 / 海面：6 类

履带坦克、双炮台、雷达设施、导弹巡逻艇、履带导弹车、六足炮座。坦克底盘与炮塔分开旋转，船只不用岛屿垫底；炮座仍沿用现有伤害、奖励与发射规则。当前没有实现原作那种炮塔和车体分别摧毁的多部件生命值。

### Boss：5 种主体

第一关航母保留；第二关改为双船体武装平台；第三关六足重炮；第四关重型旋翼机；第五关多臂分节核心。前四类采用已观察结构语言，双船体组合和具体比例为本项目原创扩展。第五关参考官方截图中的圆形关节与分节机械构造，未复制原图或原作模型。

### 场景：每关 4 个按行进距离出现的地标段落

| 关卡 | 新结构 | 新敌人的节奏 |
|---|---|---|
| 群岛 | 岛岸桥梁、简易跑道、机库、栈桥与储罐 | 开场螺旋桨编队，随后喷气机、直升机，后段装甲机 |
| 港湾 | 集装箱码头、桥架、储罐、并行管道 | 解锁截击机和巡逻艇 |
| 沙谷 | 桁架桥、道路标线、设施院落、残墙 | 解锁双尾梁机与导弹车 |
| 冰川 | 岩岸桥梁、输送管线、维护站 | 解锁重型直升机与六足炮座 |
| 轨道 | 拼接甲板、格栅、管道和跨接结构 | 解锁无人机；与已有种类交替 |

这些地标使用本项目关卡设定，不是把原作关卡逐段搬入。建筑、管道、桥梁目前为场景构造，不计可破坏敌人。新增构造放在战机和主要弹道下方。

## 掉落与密度

保留已实现的约束：前 28 秒无补给箱；两次补给至少间隔 22 秒、8 次新击杀；场上最多一个补给；屏幕外击杀不消耗补给机会；道具类型分五关解锁。普通编队最多 5 架，直升机编队最多 2 架，重型直升机单机入场；沿用波次间隔及在场数量上限，不为展示新模型把所有种类挤在开场。

## 验证边界

核心逻辑、模拟器实景和模型检查的最终结果记录到 `VALIDATION.md`。`-shape-demo` 是仅 Debug + UI testing 可用的静态检视场景，用于同时检查模型、材质、纵横投影；它不是正常关卡的敌人密度证据。真实波次另外运行五关场景测试。

仍未验证：真机性能、完整原版敌人/关卡/多部件 Boss 行为；不声称整款游戏已达到 1:1 复刻。
