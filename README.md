# EAGLE FORCE · 苍穹突击

原创 iOS 科幻街机射击游戏，SceneKit 实时 3D 世界 + SwiftUI 界面，SpriteKit 仅承载时钟与触控，支持 iPhone / iPad、iOS 17+。当前为前五关的本地可玩版本，尚未提交 App Store。

## 当前 UI

第十四版以真机参考的界面构成为准：黑底琥珀雷达地图、青色圆形 START、飞机蓝图机库、数码战斗 HUD 和圆环暂停页。实际运行截图与差异记录见 [v14](docs/screenshots/v14/README.md)，逐页设计见 [参考研究](docs/SKY_FORCE_STUDY.md)。

第十六版统一战斗材质与比例：独立黄翼侦察机、四发重装机、红色截击机，履带坦克与双管炮，磨损金属补给、正常比例救援飞行员，深蓝海面与带碎浪的礁岛。重新编排开局敌群和逐关补给解锁。实际画面见 [v16](docs/screenshots/v16/README.md)，规则见 [设计文档](docs/GAME_DESIGN.md)，素材与提示词见 [来源记录](docs/ASSET_PROVENANCE.md)。

## 玩法

冷启动先播放三段「破晓防线」剧情，林汐语音与字幕同步出现。可继续或跳过，播完自动进入关卡选择；从战斗或后台返回不重复开场。

拖动任意位置相对移动，战机带短暂追随惯性并自动开火；用 EMP 清弹并获得短暂无敌。接回金色 SOS 信标中的立体飞行员可补充 EMP。星晶使用金色立体星形；橙色闪电火力、蓝色盾牌护盾、绿色十字维修有独立符号与中文短标签。通关、全救援、护甲至少 60% 各授予一枚勋章。首通与新勋章奖励仅一次，重玩仍可获得局内收益；失败保留 25%，撤离不结算。

新增三种限时主武器：青色激光贯穿直线，绿色散弹七路扇射，紫色雷电最多连锁三个附近目标。拾取后持续 12 秒，新拾取切换类型并刷新时间；可叠加原有 8 秒火力过载。装备箱前 28 秒不出现；之后需距离上次掉落至少 22 秒、增加至少 8 次击杀，且同屏没有其他装备箱。第 1 关维修/过载，第 2 关新增护盾/散弹，第 3 关新增激光，第 4 关新增护航机，第 5 关新增雷电。首次装备优先展示本关新类型；满血时跳过维修箱。护航机拾取后自动跟飞射击，本次出击最多 3 架，满编再次拾取兑换 60 星晶。战斗 HUD 显示武器倒计时和编队数量，林汐首次获得装备时提供战术支援。

五关依次解锁：碧潮群岛（纵）、霓虹港湾（横）、赤砂熔谷（纵）、极光裂隙（横）、零点天穹（纵）。每关有独立编队时间线和 Boss；按时间表进入编队，清场与过载不提前消耗后续波次；前两波各 3 架，后续 4–5 架，前一编队最多剩 3 架才进入下一波，总数最多 8 架，Boss 前 4 秒停止入场。侦察机单发瞄准，重装机三发扇射；第 2 关第 4 波开始引入快速双发截击机，林汐提供一次战术解说。普通、地面与 Boss 敌弹速度在原基础上提高 50%。敌机与 Boss 到达玩家侧后方后停止发射新弹幕及激光；地面单位保留前方 40 单位的开火安全距离，已经发射的弹丸和激光预警继续正常运行。战区全部使用实时 SceneKit 几何、光照与材质，包含不规则海岛、夜港建筑、沙丘、冰川岩壁、轨道设施和星体。地面敌军采用立体坦克、双管炮塔和雷达站造型，可碰撞、有耐久条，会朝玩家瞄准射击。基础机炮击中三类单位 4/8/14 次可摧毁，掉落一枚星晶；沿用地面装甲的 EMP 免疫，发出的子弹可被 EMP 清除。地面单位每 31–35 秒出现一次，始终留出宽阔绕行空间；普通地表景物可飞越。战役外使用星晶升级主炮、装甲和回收范围。

## 本地运行

依赖完整 Xcode、iOS Simulator runtime，无第三方包。所有构建通过根目录脚本：

```sh
./build.sh run       # 构建，覆盖安装至专用 EagleForce-QA 模拟器并打开
./build.sh test      # Swift Testing：核心战斗、奖励、升级、存档
./build.sh check     # 核心测试 + iOS UI 测试 + 安装运行
./build.sh ui-test   # UI 测试（五个战区、竖屏内两种飞行方向、暂停、EMP、机库、全局音乐）
./build.sh build     # 仅构建模拟器 App
UI_TEST_FILTER=EagleForceUITests/EagleForceUITests/testVictorySavesRewardsAndUnlocksNextMission ./build.sh ui-test # 单项 UI 回归
./build.sh ios       # Release 真机架构编译；无签名，不可直接安装
DEVELOPMENT_TEAM=你的团队ID ./build.sh archive  # 签名归档，不上传
./build.sh clean     # 清理本项目构建产物
```

脚本在本地构建，启动 caffeinate、清理 Go 构建缓存和本项目 `.artifacts`，退出时清理临时 DerivedData 并释放自己的 caffeinate。覆盖安装保留 Application Support，不卸载 App、不清除用户进度。产物和验证日志在 `build/`，不入 Git。指定模拟器可设置 `SIMULATOR_UDID`；`UI_TEST_FILTER` 可用逗号分隔多个完整测试路径。

## 结构

- `Sources/Core/Campaign.swift`：关卡、波次、升级、幂等奖励、本地原子存档。
- `Sources/Core/GameWorld.swift`：独立于 UI 的战斗模拟，碰撞、掉落、救援、弹幕、Boss。
- `Sources/App/BattleScene.swift`：战斗时钟、触控坐标、音效、HUD 同步；空 SpriteKit 场景不绘制游戏对象。
- `Sources/App/SpriteArt.swift`：ModelArt 模型、CombatRenderer 战斗渲染、TerrainScene 环境、ModelPreview 模型预览/序幕；沿用文件名但已无精灵绘制。
- `Sources/App/CampaignView.swift` / `BattleView.swift`：全屏战役地图、机库、档案与游戏覆盖界面。
- `Resources/`：原创生成图、图标、隐私清单。

存档：App 沙盒 `Application Support/EagleForce/pilot.json`。读取失败不覆盖原档；保存失败不发放奖励、不扣升级款。删除 App 会失去本机存档，当前没有云同步。

Debug 支持 `-ui-testing`（独立临时存档）、`-unlock-missions`（预览关卡）、`-mission 1…5`（直接进入指定战区）、`-autopilot`（仅与 `-ui-testing` 一起使用的加速无敌瞄准机器人，用于结算 UI 测试）。另有 `-ui-testing -weapon-demo laser|spread|lightning -mission 1|2`，通过实际碰撞领取武器和三架护航机，并放置耐久目标用于渲染检查。Release 不接受这些测试参数。正常玩家路径始终按通关顺序解锁。

## 战斗表现第三版

紧凑航电 HUD、分段机体耐久、机库整备台与改装行；补给改为 SceneKit 实时光照几何体。战机侧倾与投影形成高度感，障碍物受击短暂降低透明度并随损伤变暗。碰撞触发战机闪烁；耐久减少出现轻量窄边缘晕影，低血量只保留淡红边缘。致命伤后战机翻滚、缩小下坠、拖烟起火，1.75 秒撞击并爆炸、飞散残片，3.4 秒后才结算。暂停和后台挂起同样冻结坠毁阶段。

第三版当时采用精细地表/战机精灵与实时 3D 补给结合的 2.5D 表现。第六版进一步接入实时地形网格，战机仍为精灵；真机性能和最终美术验收仍需完成。


第四版加入编队位移、1×/1.5×/2× 倍速、按关卡递增的 Boss 弹幕、快速吸附、受损烟火、金色 SOS 救援提示、原创背景音乐与独立战斗音效。所有关卡保持竖屏，第二/四关使用侧视背景与弯曲碰撞峡道。通关结算返回地图自动选中下一关，并沿航线飞行转场。

第五版当时更名为「苍穹突围」。战机移动只做侧倾旋转，护盾独立跟随位置并保持正圆；SOS 改为戴头盔、橙色飞行服、挥手求援的 Q 版人物。Boss 交替使用短促连射与恢复窗口，半血后加快节奏，弹幕角度与激光间隔也有变化。Boss 被击落后播放 5.2 秒的连环爆炸、失控下坠、浓烟与解体动画，动画结束才结算，倍速不缩短该片段。32 秒原创循环音乐覆盖地图、机库、战斗与结算；暂停战斗保留音乐，退到后台暂停，回到前台恢复。


## 第六版：苍穹突击

首页取消底部标签栏与大块说明卡片，采用全屏战区地图、右上角设置、整备机库和大号出击按钮。中文显示名改为「苍穹突击」，包标识、存档位置及进度兼容性不变。

普通侦察机与截击机基础命中次数按第 1–5 关为 **1 / 1 / 2 / 2 / 3**；装甲敌机为 **1 / 2 / 2 / 3 / 3**。翼炮命中普通敌机的最低有效伤害与基础主炮一致，升级与过载可以减少次数。Boss 和地面高塔继续采用独立耐久。

纵向关卡使用带高度与法线的纹理网格、斜俯视相机、立体设施和实时定向光/投影；港湾、冰川保留远景原画，在近景加入挤出的三维岩壁。岩壁轮廓和碰撞共用同一通道函数。新增背景设施是可飞越的装饰，带耐久条的高塔仍是可破坏障碍。地形滚动跟随战斗时钟与倍速，暂停同步冻结。


## 第七版：破晓防线剧情与角色通讯

前五关串成夺回天穹防御网的原创战役。新增女性通讯官林汐和五位敌方指挥官，六张原创人物头像、战前人物档案、Boss 登场台词、战术解析与战后故事。地图点击「战情与人物」查看和试听，战斗中自动触发头像字幕与林汐中文语音，暂停可回顾通讯记录。

林汐使用本机 iOS 普通话合成声音，优先女声；语音可独立关闭，字幕常驻功能不受影响。暂停、后台与撤离停止播读，语音中背景音乐自动降低。旧存档兼容，解锁仍复用通关勋章。详见 [剧情设计](docs/STORY_DESIGN.md)。

新增核心 `Story.swift` 管理角色、剧情和按战况触发的通讯；`RadioVoice.swift` 管理系统语音与混音，`StoryViews.swift` 提供战情、人物和通讯记录界面。


## 第八版：动态补兵与入场剧情

增强火力时更快补充前方目标，场上总量受限；所有敌弹提速 50%。道具以金色菱形、绿色十字、蓝色盾牌、橙色闪电及短标签区分，横向飞行时保持正向。地面敌军改为会射击的简洁坦克、炮塔和大头机器人，救援人物改为大头火柴人。启动先播放三段林汐通讯序幕，结束后直接进入选关，支持继续和跳过。

详见 [节奏与辨识规则](docs/GAMEPLAY_TUNING.md)、[剧情设计](docs/STORY_DESIGN.md)、[验证记录](docs/VALIDATION.md)。最新实际截图保存在 `docs/screenshots/v8/`。


## 第十版：全场景实时 3D

背景、主机、敌机、五种 Boss、护航机、坦克/炮塔/雷达站、九类补给与救援、弹丸、激光、雷电、EMP、烟雾和爆炸均由 SceneKit 实时几何渲染。战役地图、航线转场飞机、机库和三段序幕也使用同一模型体系。第十二版按 Ship-* 原画分别描出主机、截击机、重装炮艇和母舰轮廓，使用带厚度、机身起伏、侧壁与底面的网格承载原画 UV 贴图；Terrain-*、Side-* 和 CampaignMap 仍保留作历史素材。HUD、字幕、人物通讯头像和系统图标继续作为清晰的二维界面覆盖。

战机采用挤出机翼、机身、独立发动机与座舱；五个 Boss 分别增加尾梁、双炮、重装舱、宽翼、环形核心。金属粗糙度、定向光、动态阴影和轻量泛光统一表现。正交镜头保持射击玩法的平面碰撞与相对拖动，横向关卡旋转镜头但不旋转设备。升降、侧倾、道具悬浮与坠落改变真实三维姿态；它不是自由飞行的 6 自由度游戏。

战机是依据原画构建的浮雕式立体网格，沿用原图中的面板、涂装与光影，另有实时受光和实体发动机/炮塔。尚未使用专业 DCC 逐部件精修模型、独立侧面纹理或物理材质贴图；大角度侧视的细节仍有限。粒子使用有上限的低多边形碎片和烟团，降低模式减少数量；暂停同时冻结世界和效果。关卡、武器、剧情、奖励和存档结构没有改动。

Debug 新增 `-ui-testing -boss-demo -mission 1…5`，通过正常 Boss 生成逻辑快速进入接战，供模型和两种飞行轴的投影校验使用。三维实现说明见 [3D 渲染设计](docs/RENDERING_3D.md)。


## 真机参考学习与视觉迭代

2026-10-27 实际观察手机中的 Sky Force 与 Sky Force Reloaded，保存 15 张参考截图，完成后关闭两款游戏并释放设备队列。观察、玩法取舍、五关共用实现与未采集部分见 [真机研究与设计文档](docs/SKY_FORCE_STUDY.md)。参考图片仅在 docs 中，不进入发行资源。

地图新增三项奖励目标与已领取状态；地表增加水面/岩层细节与边缘空气层，敌弹、爆炸和补给收集反馈进一步分层；救援与一般补给使用独立原创音效。本轮没有实听参考游戏的声音，音效实现不是原版录音复刻。

## 第十一版：飞行手感与立体侧倾

触控只推动目标位置，真实战机以约 140 ms 的响应时间追随，最大速度 520 单位/秒，排队位移最多 90 单位。松手只保留剩余位移的 18%（不超过 16.2 单位）；取消手势、暂停、坠毁或 Boss 陨落立即清除待移动距离。横竖关卡使用同一套世界坐标规则，倍速不改变触控响应。

战机根据真实位移速度平滑侧倾（上限约 45°）、俯仰并轻微偏航，右移时右翼下沉；护航机同步倾斜。实体尾翼进一步突出厚度。低效果模式保留四分之一姿态幅度。道具去掉外围圆环，拾取改为短促亮点；护盾、EMP 与爆炸效果保留。

Debug 的 `-ui-testing -flight-test -flight-demo -weapon-demo laser -mission 1`（或 2）使用正式移动和绘制路径，在转向中途定格以复核姿态与无环道具。真实拖动测试另行验证横竖关卡的侧倾与暂停后位置稳定。
